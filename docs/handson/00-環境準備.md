# Lab 0: 環境準備

## 🎯 目的
このLabでは、AZ-400ハンズオンコースで使用する環境をセットアップします。

## ⏱️ 所要時間
約30分

## 📋 前提条件
- インターネット接続
- メールアドレス（Azure/GitHub アカウント用）
- ブラウザ（Edge または Chrome 推奨）

## 🛠️ 必要なツールとサービス

### 1. Azure サブスクリプション
無料試用版または既存のサブスクリプションを使用します。

#### 手順
1. [Azure Portal](https://portal.azure.com/) にアクセス
2. Microsoft アカウントでサインイン（持っていない場合は作成）
3. 無料試用版の場合は[こちら](https://azure.microsoft.com/free/)から登録

#### 確認方法
```powershell
# Azure CLI でログインできることを確認
az login
az account show
```

### 2. Azure DevOps Organization
無料で使用できます。

#### 手順
1. [Azure DevOps](https://dev.azure.com/) にアクセス
2. Microsoft アカウントでサインイン
3. 「+ Create new organization」をクリック
4. Organization 名を入力（例: `az400-handson-org`）
5. リージョンを選択（Japan East 推奨）

#### 確認方法
- Organization のダッシュボードが表示されることを確認
- URL: `https://dev.azure.com/{your-org-name}`

### 3. Azure DevOps プロジェクト作成

#### 手順
1. Azure DevOps Organization で「+ New project」をクリック
2. プロジェクト名: `AZ400-HandsOn`
3. Visibility: Private
4. Version control: Git
5. Work item process: Agile
6. 「Create」をクリック

### 4. GitHub アカウント
無料アカウントで十分です。

#### 手順
1. [GitHub](https://github.com/) にアクセス
2. アカウントがない場合は「Sign up」から作成
3. メール認証を完了

#### 確認方法
- GitHub にログインできることを確認

### 5. Visual Studio Code
無料のコードエディタです。

#### 手順
1. [VS Code ダウンロードページ](https://code.visualstudio.com/)にアクセス
2. OS に応じたインストーラーをダウンロード
3. インストーラーを実行

#### 推奨拡張機能
以下の拡張機能をインストール：
- Azure Pipelines
- Azure Account
- YAML
- GitLens
- Azure Repos

```powershell
# コマンドラインからまとめてインストール
code --install-extension ms-azure-devops.azure-pipelines
code --install-extension ms-vscode.azure-account
code --install-extension redhat.vscode-yaml
code --install-extension eamodio.gitlens
```

### 6. Git クライアント

#### Windows
```powershell
# Git がインストールされているか確認
git --version

# インストールされていない場合
winget install Git.Git
```

#### 確認方法
```powershell
git --version
# 出力例: git version 2.43.0
```

#### 初期設定
```powershell
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"
```

### 7. .NET SDK 8.0
Lab 3（Azure Artifacts）で使用します。

#### 手順
1. [.NET ダウンロードページ](https://dotnet.microsoft.com/download)にアクセス
2. .NET 8.0 SDK をダウンロード
3. インストーラーを実行

#### 確認方法
```powershell
dotnet --version
# 出力例: 8.0.100
```

### 8. Azure CLI
Azure リソースの管理に使用します。

#### Windows
```powershell
# インストール
winget install Microsoft.AzureCLI

# または MSI インストーラーをダウンロード
# https://learn.microsoft.com/cli/azure/install-azure-cli-windows
```

#### 確認方法
```powershell
az --version
# Azure CLI のバージョン情報が表示されることを確認
```

#### ログイン
```powershell
az login
# ブラウザが開くので認証を完了

# サブスクリプション一覧を表示
az account list --output table

# 使用するサブスクリプションを設定
az account set --subscription "your-subscription-id"
```

### 9. Azure DevOps CLI 拡張機能

```powershell
# Azure DevOps 拡張機能をインストール
az extension add --name azure-devops

# バージョン確認
az extension show --name azure-devops
```

## 🔑 認証情報の設定

### GitHub と Azure DevOps の連携

#### Personal Access Token (PAT) の作成 - GitHub

1. GitHub の Settings → Developer settings → Personal access tokens → Tokens (classic)
2. 「Generate new token」をクリック
3. Note: `AZ400-HandsOn`
4. Expiration: 90 days
5. Scopes を選択:
   - `repo` (すべてのサブスコープ)
   - `workflow`
   - `read:org`
6. 「Generate token」をクリック
7. **トークンをコピーして安全な場所に保存**（再表示不可）

#### Personal Access Token (PAT) の作成 - Azure DevOps

1. Azure DevOps の右上のユーザーアイコン → Personal access tokens
2. 「+ New Token」をクリック
3. Name: `AZ400-HandsOn`
4. Organization: 作成した Organization を選択
5. Expiration: 90 days
6. Scopes を選択:
   - `Build`: Read & execute
   - `Code`: Read, write, & manage
   - `Packaging`: Read, write, & manage
   - `Project and Team`: Read, write, & manage
   - `Work Items`: Read, write, & manage
7. 「Create」をクリック
8. **トークンをコピーして安全な場所に保存**（再表示不可）

## 🔍 トラブルシューティング

### Azure CLI のログインができない
```powershell
# デバイスコードフローを使用
az login --use-device-code

# または特定のテナントでログイン
az login --tenant "tenant-id"
```

### Azure DevOps CLI が動作しない
```powershell
# 拡張機能を削除して再インストール
az extension remove --name azure-devops
az extension add --name azure-devops

# キャッシュをクリア
az cache purge
```

### Git の認証エラー
```powershell
# Git Credential Manager の確認
git config --global credential.helper

# 再設定
git config --global credential.helper manager-core
```
