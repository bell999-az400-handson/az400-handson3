### 2. Azure DevOps Organization
無料で使用できます。

3. 「+ Create new organization」をクリック

### 3. Azure DevOps プロジェクト作成

#### 手順

**方法1: Web ブラウザで作成**

1. Azure DevOps Organization で「+ New project」をクリック
2. プロジェクト名: `az400-handson3`
3. Visibility: Private
4. Version control: Git
5. Work item process: Agile
6. 「Create」をクリック

**方法2: Azure DevOps CLI で作成（推奨）**

**⚠️ 事前準備**: このコマンドを実行する前に、Azure DevOps の Personal Access Token (PAT) を作成してください（詳細は下記「🔑 認証情報の設定」セクション参照）。

```powershell
# 方法A: 環境変数で PAT を設定（推奨）
$env:AZURE_DEVOPS_EXT_PAT = "your-pat-token-here"

# デフォルトの Organization を設定
az devops configure --defaults organization=https://dev.azure.com/bell999

# プロジェクトを作成
az devops project create `
  --name az400-handson3 `
  --description "AZ-400 ハンズオン3回目用プロジェクト" `
  --visibility private `
  --source-control git `
  --process Agile

# 方法B: 対話的にログイン
az devops login --organization https://dev.azure.com/bell999
# プロンプトでPATを入力

# その後プロジェクト作成
az devops project create `
  --name az400-handson3 `
  --description "AZ-400 ハンズオン3回目用プロジェクト" `
  --visibility private `
  --source-control git `
  --process Agile

# プロジェクトが作成されたことを確認
az devops project show --project az400-handson3 --output table
```

#### 確認方法
```powershell
# プロジェクト一覧を表示
az devops project list --output table

# または Web ブラウザで確認
# https://dev.azure.com/bell999/az400-handson3
```

## 🔑 認証情報の設定

### GitHub と Azure DevOps の連携

#### Personal Access Token (PAT) の作成 - GitHub

1. GitHub の Settings → Developer settings → Personal access tokens → Tokens (classic)
2. 「Generate new token」をクリック
3. Note: `az400-handson3`
4. Expiration: 90 days
5. Scopes を選択:
   - `repo` (すべてのサブスコープ)
   - `workflow`
   - `read:org`
6. 「Generate token」をクリック
7. **トークンをコピーして安全な場所に保存**（再表示不可）

#### Personal Access Token (PAT) の作成 - Azure DevOps

1. Azure DevOps の右上のユーザーアイコン → Personal access tokens
2. 「+ New Token」をクリック
3. Name: `az400-handson3`
4. Organization: 作成した Organization を選択
5. Expiration: 90 days
6. Scopes を選択:
   - `Build`: Read & execute
   - `Code`: Read, write, & manage
   - `Packaging`: Read, write, & manage
   - `Project and Team`: Read, write, & manage
   - `Work Items`: Read, write, & manage
7. 「Create」をクリック
8. **トークンをコピーして安全な場所に保存**（再表示不可）

## 📝 環境変数の設定

### 方法の選択

環境変数の設定方法は、セキュリティと利便性のバランスで選択してください：

| 方法 | セキュリティ | 利便性 | 推奨シーン |
|------|------------|--------|----------|
| セッション単位 | ⭐⭐⭐⭐⭐ | ⭐⭐ | 一時的な作業・学習中 |
| .env ファイル | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ | **プロジェクト作業（推奨）** |
| PowerShell プロファイル | ⭐⭐ | ⭐⭐⭐⭐⭐ | 個人環境（要注意） |

### 方法1: セッション単位（一時的）

PowerShell起動ごとに手動設定する方法です。最も安全ですが、毎回設定が必要です。

```powershell
# PowerShell 起動後に毎回実行
$env:AZURE_DEVOPS_EXT_PAT = "your-azure-devops-pat-token"
$env:AZURE_DEVOPS_ORG = "https://dev.azure.com/bell999"
$env:AZURE_DEVOPS_PROJECT = "az400-handson3"

# 設定後、コマンド実行可能
az devops configure --defaults organization=https://dev.azure.com/bell999
az devops project list
```

### 方法2: .env ファイル（推奨）

プロジェクトルートに `.env` ファイルを作成し、`.gitignore` でバージョン管理から除外します。

**⚠️ 注意**: PAT の値は「🔑 認証情報の設定」セクションで作成した**トークンの値**（52文字程度の長い文字列）を使用してください。Token名（`az400-handson3`）ではありません。

```powershell
# .env ファイルを作成
@"
AZURE_DEVOPS_EXT_PAT=your-actual-pat-token-value-here
AZURE_DEVOPS_ORG=https://dev.azure.com/bell999
AZURE_DEVOPS_PROJECT=az400-handson3
"@ | Out-File -FilePath .env -Encoding utf8

# .gitignore に追加（重要！GitにPATをコミットしない）
if (!(Test-Path .gitignore)) {
    New-Item -ItemType File -Path .gitignore
}
".env" | Out-File -Append -FilePath .gitignore -Encoding utf8

# .env ファイルから環境変数を読み込む
Get-Content .env | ForEach-Object {
    if ($_ -match '^([^=]+)=(.*)$') {
        Set-Item -Path "env:$($matches[1])" -Value $matches[2]
    }
}

# 読み込みを確認
echo $env:AZURE_DEVOPS_EXT_PAT
```

**💡 便利なヘルパー関数**

PowerShell プロファイルに追加すると、毎回 `.env` を簡単に読み込めます：

```powershell
# 関数を定義（$PROFILE に追加推奨）
function Load-DotEnv {
    if (Test-Path .env) {
        Get-Content .env | ForEach-Object {
            if ($_ -match '^([^=]+)=(.*)$') {
                Set-Item -Path "env:$($matches[1])" -Value $matches[2]
            }
        }
        Write-Host "✅ .env ファイルを読み込みました" -ForegroundColor Green
    } else {
        Write-Host "❌ .env ファイルが見つかりません" -ForegroundColor Red
    }
}

# 使用方法
Load-DotEnv
```

### 方法3: PowerShell プロファイル（自動読み込み）

PowerShell起動時に自動で環境変数を設定します。

```powershell
# プロファイルの場所を確認
echo $PROFILE
# 通常: C:\Users\<username>\Documents\PowerShell\Microsoft.PowerShell_profile.ps1

# プロファイルが存在しない場合は作成
if (!(Test-Path -Path $PROFILE)) {
    New-Item -ItemType File -Path $PROFILE -Force
}

# プロファイルを編集
notepad $PROFILE

# 以下を追加
$env:AZURE_DEVOPS_EXT_PAT = "your-pat-token-value"
$env:AZURE_DEVOPS_ORG = "https://dev.azure.com/bell999"
```

**⚠️ セキュリティリスク**: PATが平文でファイルに保存されます。個人PCでのみ使用してください。

### 環境変数の確認

```powershell
# 設定された環境変数を確認
echo $env:AZURE_DEVOPS_EXT_PAT
echo $env:AZURE_DEVOPS_ORG
echo $env:AZURE_DEVOPS_PROJECT

# または一覧表示
Get-ChildItem env:AZURE_DEVOPS_*
```

**💡 ヒント**: 
- PAT は「🔑 認証情報の設定」セクションで作成した**トークンの値**（長い文字列）です
- Token名（`az400-handson3`）ではありません
- PATは再表示できないので、作成時に必ず保存してください
